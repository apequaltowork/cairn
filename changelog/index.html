What's New

Every Cairn release, newest first. Chrome updates extensions on its own schedule, so it can take a day or two before a new version reaches you.

1.2.0

Latest September 3, 2026

Choose exactly which tabs go into a workspace.

  • Pick your tabs when saving. Saving a workspace used to take everything open. Now you can choose — keep All tabs, or switch to Choose tabs and tick just the ones you want, with select-all and clear. All tabs stays the default, so nothing changes unless you want it to.
  • Works when updating, too. The same picker appears on Update workspace with current tabs, so you can refresh a workspace from part of your window instead of all of it.
  • Live counts. The tab and group totals update as you tick, so you can see what you're about to save before you save it.
  • Renamed. Cairn is now listed as “Cairn — Tab Manager, Workspaces & Session Saver” so it's findable by what it actually does. Same extension, same data — only the name on the store listing changed.

1.0.0

August 25, 2026

First public release.

  • Workspaces. Save every open tab as a named workspace — tab groups, pinned state and order all preserved — then close everything and restore it in one click.
  • Universal search. One search box across open tabs, saved workspaces, history, bookmarks and workspace notes.
  • Notes. Each workspace carries its own notes, next to the tabs they're about.
  • Cleanup. Finds duplicate and stale tabs and suggests groups from shared domains. Nothing closes or moves without you confirming it.
  • Temporary tabs. Mark a tab to expire in an hour, today, tomorrow or a time you pick, and get a reminder instead of forgetting it in the pile.
  • Optional AI. Ask a workspace to summarise itself or find themes across its tabs. Off by default, uses your own API key, and shows you exactly what would be sent before anything leaves your device.
